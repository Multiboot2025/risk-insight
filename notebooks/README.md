# notebooks/

Notas de exploración y modelado del componente analítico de FraudIA Claims. Por ser un proyecto TypeScript, los "notebooks" se mantienen como Markdown ejecutable (snippets + conclusiones) en vez de `.ipynb`.

- `01_exploracion_datos.md` — EDA inicial de siniestros sintéticos.
- `02_modelo_fraude.md` — diseño y pesos del motor de reglas.
- `03_evaluacion_modelo.md` — métricas y matriz de aciertos vs etiquetas conocidas.
